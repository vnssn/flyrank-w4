# FlyRank Week 4 — Accessible Components Playground

This repository contains the Week 4 FE-05 accessibility exercise for the FlyRank Frontend AI Engineering internship.

## Components

- Accessible Modal Dialog
- Accessible Tabs
- Accessible Disclosure

These components implement important keyboard and accessibility behaviors, including focus management, correct tab order, Escape-to-close handling, ARIA semantics, and disclosure toggling.

## Tech Stack

- React
- TypeScript
- Vite
- shadcn/ui / Radix UI for the comparison implementation

## Getting Started

```bash
npm install
npm run dev
```

## Verification

The project was checked with:

```bash
npm run build
npm run lint
```

The custom components were also tested with keyboard-only navigation.
